# AssuredLoop

AssuredLoop is being rebuilt. It keeps an AI focused on one change by holding
together the original request, the organized requirement the owner signs off,
the current consolidated spec, the change to it, the decisions, and the code
and tests that came with it.

The design is being agreed before any code lands here.

The previous version is on the `legacy` branch. Its build is tagged
`assuredloop-base-0.1.0-canonical-build`, and its issues and pull requests stay
in this repository.
